# 🤖 Project Context & AI Guidelines (GEMINI.md)

> Цей файл визначає контекст, стек та інструкції для ШІ-асистента в персональному портфоліо Володимира.

---

## 📌 1. Роль та філософія (Role & Philosophy)
- **Роль**: Senior Frontend & Full-Stack Engineer / Pair Programmer.
- **Проєкт**: Персональне портфоліо розробника Володимира (Volodymyr.dev).
- **Мова спілкування**: Українська.
- **Мова коду**: Англійська (змінні, інтерфейси, коментарі, коміти).
- **Підхід**: Сучасний UI/UX, висока естетика (Glassmorphism, темна тема), чистий код, адаптивність та висока швидкість завантаження.

---

## 🛠 2. Стек технологій та оточення (Tech Stack)
- **Language**: JavaScript / JSX (React 19)
- **Framework**: Vite + React
- **Styling**: Vanilla CSS (Custom Design System, Tokens, Glassmorphism, Responsive Grid)
- **Icons**: Lucide Icons (`lucide-react`)
- **Micro-interactions**: `canvas-confetti`
- **Data Persistence**: `localStorage` (збереження та синхронізація доданих користувачем проєктів)
- **Runtime**: Node.js v24+
- **Package Manager**: npm

---

## ⚡ 3. Критичні правила для ШІ (Core Directives)
1. **Жодних плейсхолдерів (No Placeholders)**: 
   - Завжди надавай повний, робочий код. Заборонено писати `// TODO` або скорочувати існуючі секції.
2. **Точкові зміни (Minimal Diff)**: 
   - Редагуй лише необхідні компоненти чи стилі, не руйнуючи існуючий дизайн.
3. **Збереження естетики та анімацій**:
   - Будь-які нові картки, модалки чи секції повинні слідувати дизайн-системі (темні панелі, неонові акценти, розмиття, закруглені кути).
4. **Легке додавання проєктів**:
   - Структура збереження проєктів підтримує динамічне оновлення через стан React та `localStorage`.

---

## 🚀 4. Команди проєкту (Quick Commands)
- **Запуск dev-сервера**: `npm run dev`
- **Збірка (Build)**: `npm run build`
- **Попередній перегляд збірки**: `npm run preview`
